# Night Watch

Текстовая ролевая игра в браузере. Северная пограничная крепость в заснеженных горах: вас,
осуждённого, привозят к её воротам, и прошлое остаётся за ними. Дальше — служба, люди крепости
и огни в лесу, о которых здесь не принято говорить.

**Играть:** https://xxmuxaxx.github.io/night-watch/

- выборы с последствиями, проверки силы, ловкости и чутья;
- пошаговый бой: защита и парирование, приёмы классов, предметы;
- свободное перемещение по крепости, время суток, распорядок и события;
- журнал целей и зацепок, отношения с персонажами;
- автосохранение и ячейки, режим «Одна жизнь», настройки шрифта и звука.

Сейчас написана первая глава.

## Разработка

Нужен Node.js 22.

```bash
npm install
npm run dev     # игра на http://localhost:5173, с панелью отладки (кнопка 🛠 или клавиша `)
npm run check   # типы, линтер, форматирование и тесты
npm run build   # сборка в dist/
```

Устройство проекта описано в [CLAUDE.md](CLAUDE.md), подсказки для генерации картинок —
в [docs/image-prompts.md](docs/image-prompts.md). Каждый push проверяется в GitHub Actions,
а с ветки `main` игра сама публикуется на GitHub Pages.
